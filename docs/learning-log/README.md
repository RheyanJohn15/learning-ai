# Learning Log

Dated entries recording what you studied, what you understood, and — most importantly — what remains unclear. The log is the primary evidence trail for roadmap progress.

## How to use

1. Copy [TEMPLATE.md](TEMPLATE.md) to `YYYY-MM-DD-short-topic.md` (for example `2026-10-12-chain-rule.md`). Multiple entries per day are fine; add a suffix.
2. Fill in what applies; mark other sections "n/a". Five minutes at the end of a session is enough.
3. Copy items from "Questions for further investigation" into the [research backlog](../research-backlog.md) if they deserve follow-up.
4. Add a row to the index below.

If the log grows large, group entries into yearly subfolders (`2026/`) and keep this index.
