# Research Backlog

One place for ideas and questions, so they are not lost and not acted on prematurely. Each item is one line. Move items between sections as they progress; never delete them — mark them dropped with a reason instead.

## Format

```text
- [Q-001] 2026-10-11 · Short description · source: link · next: what would advance it
```

| Prefix | Section |
|---|---|
| `Q` | Open question |
| `I` | Idea (untested intuition) |
| `E` | Experiment (planned, running, or done — link the record) |
| `P` | Potential research project (larger than one experiment) |

Give each item the next unused number for its prefix. An item becomes an experiment when it has a testable hypothesis; create an [experiment record](experiments/TEMPLATE.md) and move the item to **Planned experiments** with a link.

## Weekly review (5–10 minutes)

1. Add unresolved questions from recent [learning-log](learning-log/README.md) entries and follow-ups from [paper notes](papers/README.md).
2. Promote at most one or two items to **Planned experiments**.
3. Drop items that no longer matter, with a one-line reason.
