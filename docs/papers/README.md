# Paper Notes

Structured notes on research papers, one file per paper, focused on critical analysis rather than summary.

## How to use

1. Copy [TEMPLATE.md](TEMPLATE.md) to `YYYY-firstauthor-short-title.md` using the paper's publication year (for example `2017-vaswani-attention-is-all-you-need.md`).
2. Read with the three-pass method from [Phase J §4.5](../roadmap/09-research-methodology.md#45-reading-a-paper-three-passes-after-keshav). A first-pass note can be short; extend it on later passes.
3. Verify the bibliographic details against the original source (arXiv, publisher, or DOI) before saving.
4. Move follow-up experiment ideas into the [research backlog](../research-backlog.md).
5. Add a row to the index below.

## What to read

Each phase document lists the relevant papers in its **Resources** section and suggests where to start. Suggested first notes:

- During [Phase B](../roadmap/01-neural-networks.md): Rumelhart, Hinton, Williams (1986), "Learning representations by back-propagating errors".
- During [Phase D](../roadmap/03-transformers-and-llms.md): Vaswani et al. (2017), "Attention Is All You Need".
- During [Phase G](../roadmap/06-model-interpretability.md): Elhage et al. (2021), "A Mathematical Framework for Transformer Circuits".
