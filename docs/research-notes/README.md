# Research Notes

Synthesized notes on a topic, written in your own words and drawing on several sources: learning-log entries, paper notes, and experiments. Where the learning log is chronological and paper notes cover one paper each, research notes are organized by **concept** and kept up to date as understanding improves.

## What belongs here

- A derivation worth keeping in clean form (for example "backpropagation through softmax cross-entropy").
- A concept explained from first principles (for example "why attention is scaled by $1/\sqrt{d_h}$").
- A comparison across papers (for example "what activation patching variants measure").
- A current-state summary of an open question you are tracking, with claims labeled using the [claim labels](../README.md#claim-labels).

## How to use

- Name files by topic: `short-topic.md` (for example `softmax-cross-entropy-gradient.md`).
- There is no template; start each note with a one-paragraph summary and end with **Sources** (links to papers, logs, and experiments) and **Open questions**.
- Add questions to the [research backlog](../research-backlog.md).
- When a note covers a phase topic, link it from the relevant learning-log entry.
